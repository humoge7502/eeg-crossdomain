# Cross-Domain EEG Transfer-Learning Project

Zero-shot cross-paradigm transfer study across three neuromarketing/EEG
datasets (NeuMa, Restaurant-Logo, ds007406), testing whether classifiers
trained on one EEG decision-task paradigm generalize to another.

## Quick start

```bash
pip install -r requirements.txt
bash scripts/00_reproduce_all.sh --gpu 0
```

Runs the full pipeline end-to-end with checkpointing (safe to re-run after
interruption -- already-completed steps are skipped). See
`scripts/00_reproduce_all.sh` for stage-by-stage detail and the three
normalization strategies used (documented in that script's header comment).

**Assumption**: `data/processed/<name>/<name>_epochs_common.npz` is expected
to already exist (original project raw-epoch cache, predates this
reproduction script). `data/processed_v2/` is fully regenerated by this
pipeline.

## Results narrative

`results/EXPERIMENT_LOG.md` is the authoritative, dated record of every
experiment, finding, bug, and fix in this project (30 sections). Read this
first -- it explains not just what was run, but why, and documents two
significant stale-data bugs found and corrected (Section 22).

## Headline findings

1. **No zero-shot cross-paradigm transfer** across six complementary tested
   interventions (naive LODO, class-weighted LODO, engagement relabeling,
   DANN, subject-wise multitask, full-duration+CORAL) -- null result
   validated via rigorous permutation testing (N=500, within-subject
   shuffling) on all three datasets (Section 19), multi-seed robustness
   (Section 24), and a positive control confirming the pipeline itself
   works (18.6x chance accuracy on subject-ID decoding, Section 20).
2. **Small but statistically significant shared representational structure**
   between NeuMa and Restaurant-Logo encoders, despite the null classifier
   transfer -- principal-angle analysis, bootstrap-significant (95% CI
   excludes the random-subspace null), robust across 8 independent seeds
   (Sections 21, 23).
3. **One significant zero-shot transfer result across all architectures
   tested** -- a Riemannian-geometry (MDM) classifier transfers
   significantly to ds007406 (kappa=0.11, p=0.001), surviving
   Holm-Bonferroni correction across all 9 rigorous permutation tests in
   this project. This is the only significant result among 5 architectures
   x 3 datasets tested, reported as a specific, non-generalized finding
   (Sections 25-27).
